サイト概要

HopeCareAI の操作方法・よくある質問・トラブルシューティングをまとめた社内向けヘルプサイトです。エンジニアへの依頼なしに、Notionを操作するだけで記事を更新できる仕組みになっています。

公開 URL https://matsuda-orden.github.io/hopecare-help/
項目内容
ホスティングGitHub Pages（無料・HTTPS自動対応）
コンテンツ管理Notion（3つのデータベース）
更新トリガーNotionのステータスを「公開」に変更するだけ
自動更新頻度最大20分以内に自動反映（即時反映も可能）
サイト形式シングルファイルHTML（検索・アコーディオン・カテゴリ表示つき）
GitHubリポジトリgithub.com/matsuda-orden/hopecare-help

Notionのコンテンツを自動でHTMLに変換してGitHub Pagesで公開する、完全自動のCI/CDパイプラインです。

ビルド処理の流れ（詳細）

  1. 1
    Notion API で記事取得
    3つのNotionデータベースに対してAPIを呼び出し、ステータスが「公開」の記事だけを取得。段落・見出し・画像などの各ブロックをHTML文字列に変換。
  2. 2
    画像をダウンロード・白余白を自動除去
    Notionに保存された画像URLからローカルに画像をダウンロード。sharp ライブラリで上下左右の白余白を自動トリミングして images/ フォルダに保存。
  3. 3
    index.html の articles 配列を置き換え
    テンプレートの index.html 内にある const articles = [...] を、取得した記事データで丸ごと上書き。正規表現ではなくindexOf方式で確実に置換。
  4. 4
    dist/ にコピーして GitHub Pages へデプロイ
    生成した index.html と images/ を dist/ ディレクトリにコピー。peaceiris/actions-gh-pages が gh-pages ブランチに自動プッシュ。数分で公開URLに反映。

package.json 依存パッケージの定義。@notionhq/client（API呼び出し）と sharp（画像処理）を使用。 ライブラリを追加・変更するとき

記事の更新方法（Notion操作）

コードの変更は不要です。Notionを操作するだけで、最大20分以内にヘルプサイトへ反映されます。

ポイント：記事の新規作成・編集・非公開化もすべてNotionのステータス変更だけで完結します。
  1. 1
    Notionの該当データベースを開く
    「操作ガイド」「よくある質問」「トラブルシューティング」の3つのDBのいずれかを開く。
  2. 2
    記事を作成または編集する
    タイトル・本文・カテゴリを設定。画像はGoogleスライドでスクリーンショットを加工後、JPEGエクスポートして画像ブロックとして貼り付ける（詳細は「画像の処理」セクション参照）。
  3. 3
    ステータスを「公開」に変更
    これだけで完了。次の自動ビルド（最大20分後）でサイトに反映される。すぐに反映したい場合はGitHubのActionsタブから手動で「Run workflow」を実行。

自動ビルド・デプロイ（GitHub Actions）

ビルドは完全自動化されています。通常は何も操作不要です。以下が実際のワークフロー設定です。

name: ヘルプサイト ビルド & デプロイ

on:
  schedule:
    - cron: '*/20 * * * *'   # 20分ごとに自動実行
  workflow_dispatch:          # Actionsタブから手動実行も可能

permissions:
  contents: write             # gh-pagesへのプッシュ権限

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '20' }
      - run: npm ci
      - run: npm run build     # build.js 実行
        env:
          NOTION_TOKEN: ${{ secrets.NOTION_TOKEN }}
      - uses: peaceiris/actions-gh-pages@v4
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./dist  # index.html + images/ をデプロイ

手動でビルドを即時実行する手順

  1. 1
    GitHubリポジトリを開く
    github.com/matsuda-orden/hopecare-help にアクセス。
  2. 2
    「Actions」タブを開く
    上部ナビゲーションの「Actions」をクリック。左側に「ヘルプサイト ビルド & デプロイ」が表示される。
  3. 3
    「Run workflow」をクリック
    右側の「Run workflow」ボタンをクリックしてブランチ「main」のまま実行。2〜3分で公開URLに反映される。

画像の処理

Notionの記事に貼り付けた画像は、ビルド実行時に自動でサーバーからダウンロードされ、images/ フォルダに保存されてから公開されます。

白余白の自動除去（sharp）

Googleスライドで加工してJPEGエクスポートした画像には、スライドの白い余白が残ります。ビルドスクリプトが sharp ライブラリを使って自動的に除去します。

// build.js — 画像の余白トリミング処理
const before  = await sharp(filepath).metadata();
const trimmed = await sharp(filepath).trim({ threshold: 50 }).toBuffer();
const after   = await sharp(trimmed).metadata();
fs.writeFileSync(filepath, trimmed);

// ビルドログに変化を記録
if (before.width !== after.width || before.height !== after.height) {
  console.log(`✂️  余白削除: ${before.width}×${before.height} → ${after.width}×${after.height}`);
}

画像の作り方（推奨手順）

  1. 1
    対象画面のスクリーンショットを撮る
    PCまたはスマートフォンで操作画面をキャプチャ。
  2. 2
    Googleスライドに貼り付けて加工
    スクリーンショットをGoogleスライドに配置。グレーアウト・強調枠・矢印などを追加。スライドサイズは横長（16:9）推奨。縦長スマートフォン画面の場合は、スライド上でトリミングして不要な余白を取り除いておく。
  3. 3
    スライドをJPEGでダウンロード
    Googleスライドの「ファイル」→「ダウンロード」→「JPEG画像（.jpg）」。白余白はビルド時に自動除去される。
  4. 4
    Notionの記事に画像ブロックとして貼り付ける
    Notionの記事内でJPEGファイルをドラッグ＆ドロップ。次のビルドで自動的に取得・処理される。
注意：ピンク・青など白以外の背景色を含む画像は自動トリミングが効きません（sharpは左上ピクセルの色を基準に余白を検出するため）。この場合はGoogleスライド上でトリミングしてからエクスポートしてください。

UIの機能

freee・SmartHR・MoneyForward などの企業ヘルプサイトを参考に、ゼロからリデザインしました。シングルHTMLファイルで動作し、外部CDNへの依存はありません。

機能説明
全文検索 検索ボックスにキーワードを入力すると、記事タイトル・本文をリアルタイムで絞り込み。JavaScriptのみで実装（サーバー不要）。
カテゴリカードグリッド ページ上部にカテゴリ一覧をカードグリッドで表示。クリックするとそのカテゴリのセクションにスムーズスクロール。
アコーディオン記事 各記事は折りたたみ式。タイトルをクリックで展開・閉じる。別の記事を開くと前の記事は自動で閉じる。
記事内「閉じる」ボタン 記事を読み終えた後、本文末尾のボタンで記事を閉じられる。スクロールバックなしで次の記事に進める。
スクロール制御 記事を開くと自動的にその記事の先頭にスクロール。ヘッダーの高さ分だけオフセット補正済み。
レスポンシブ対応 スマートフォン・タブレット・PCに対応。カテゴリグリッドはauto-fillで自動調整。

認証情報・シークレット

すべての認証情報はGitHub Secretsに保管されています。コードにはハードコードされておらず、外部から参照できません。

シークレット名内容管理場所
NOTION_TOKEN Notion Integration のAPIトークン（ntn_xxx 形式）。NotionのデータベースAPIアクセスに使用。 GitHubリポジトリ → Settings → Secrets and variables → Actions
GITHUB_TOKEN GitHub Pagesへのデプロイに使用。GitHub Actionsが実行ごとに自動生成・付与するため、手動設定不要。 GitHub Actions が自動管理（変更不要）

Notion Integration の設定場所

NotionのシークレットトークンはNotion側の設定から確認・再発行できます。

Notion → 「設定」→「インテグレーション」→「HopeCareAI ヘルプサイト」→ トークンを確認

GitHubのSecrets更新: リポジトリ → Settings → Secrets → NOTION_TOKEN → Update

注意：Notion Integration のトークンには有効期限があります。期限切れになるとビルドが失敗し、サイトが更新されなくなります。期限が近づいたらNotion側でトークンを再発行し、GitHubのSecretsを更新してください（コードの変更は不要です）。

今後の対応事項

対応項目詳細優先度
Notionトークンの期限確認・再発行 現行のIntegrationトークンの有効期限を確認。切れる前にNotionで再発行し、GitHubのSecretsを更新する。切れるとサイトが自動更新されなくなる。 高
不要なPersonal Access Tokenの削除 作業中に一時使用したGitHub PATが残っている可能性あり。GitHub → Settings → Developer Settings → Personal access tokens で確認・削除。 高
操作動画コンテンツの掲載 3分程度の操作動画を掲載予定。GitHubのファイルサイズ上限（100MB）を考慮し、YouTube限定公開 + iframe埋め込みを推奨。Notionへの動画直貼りはファイルサイズによっては問題が生じる可能性あり。 中
カスタムドメインの設定（任意） 現在のURLは matsuda-orden.github.io/hopecare-help/。独自ドメイン（例: help.hopecare.ai）への変更はGitHub Pages の Custom domain 設定から可能。 低
